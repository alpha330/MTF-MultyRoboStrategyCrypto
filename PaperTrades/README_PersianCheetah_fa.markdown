# PersianCheetah_Scalper_Bybit

## درباره ربات
**PersianCheetah_Scalper_Bybit** یک ربات معاملاتی خودکار برای اسکلپینگ در صرافی Bybit است که با زبان پایتون نوشته شده و در تایم‌فریم 1 دقیقه فعالیت می‌کند. این ربات از استراتژی مبتنی بر اندیکاتورهای RSI و باندهای بولینگر استفاده می‌کند و از قابلیت‌هایی مانند **Hedged Mode**، **Trailing Stop**، و **Trailing Profit** پشتیبانی می‌کند. جفت‌ارزهای مورد استفاده شامل BTC/USDT، ETH/USDT، و XRP/USDT هستند.

### ویژگی‌ها
- **استراتژی اسکلپینگ:** استفاده از RSI (دوره 14) و باندهای بولینگر (دوره 20) برای سیگنال‌های ورود و خروج.
- **Hedged Mode:** امکان باز کردن پوزیشن‌های Long و Short همزمان.
- **مدیریت ریسک:** ریسک هر معامله حداکثر 1٪ از موجودی والت.
- **Trailing Stop و Trailing Profit:** حد ضرر و سود متحرک برای بهینه‌سازی سود و کاهش ضرر.
- **پیپر تریدینگ:** شبیه‌سازی معاملات بدون ریسک واقعی.
- **نوتیفیکیشن تلگرام:** ارسال گزارش‌های معاملات و وضعیت ربات به تلگرام.
- **پشتیبانی از جفت‌ارزها:** BTC/USDT، ETH/USDT، و XRP/USDT.
- **اهرم:** 10x برای BTC و ETH، 5x برای XRP.

## پیش‌نیازها
- Python 3.8 یا بالاتر
- حساب Bybit با API Key و Secret
- حساب تلگرام و توکن ربات تلگرام
- سیستم‌عامل: لینوکس، ویندوز، یا مک

## نصب
1. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/your-repo/PersianCheetah_Scalper_Bybit.git
   cd PersianCheetah_Scalper_Bybit
   ```

2. **نصب کتابخانه‌ها:**
   ```bash
   pip install -r requirements.txt
   ```

3. **ایجاد فایل .env:**
   یک فایل `.env` در ریشه پروژه بسازید و متغیرهای زیر را اضافه کنید:
   ```env
   TELEGRAM_TOKEN_PAPER1M_10=your_telegram_bot_token
   TELEGRAM_CHANAL_ID=your_telegram_chat_id
   BYBIT_LIVE_API_KEY=your_bybit_api_key
   BYBIT_LIVE_API_SECRET=your_bybit_api_secret
   ```

4. **ساخت فایل requirements.txt:**
   ```bash
   echo -e "ccxt==2.9.5\npandas==2.0.3\nta==0.10.2\npython-telegram-bot==20.3\npython-dotenv==1.0.0\ntenacity==8.2.2" > requirements.txt
   ```

## استفاده
1. **اجرای ربات:**
   ```bash
   python PersianCheetah_Scalper_Bybit.py
   ```

2. **دستورات تلگرام:**
   - `/start`: شروع ربات‌ها
   - `/stop`: توقف ربات‌ها
   - `/status`: نمایش وضعیت ربات‌ها
   - `/positions`: نمایش آمار پوزیشن‌ها

## نکات مهم
- **بک‌تست:** قبل از استفاده در محیط لایو، ربات را با داده‌های تاریخی بک‌تست کنید.
- **مدیریت ریسک:** اطمینان حاصل کنید که تنظیمات Trailing Stop (0.3-0.5٪) و Trailing Profit (0.5٪) با استراتژی شما هماهنگ است.
- **کارمزدها:** کارمزد Maker (0.02٪) در محاسبات لحاظ شده است. در صورت استفاده از سفارشات Taker، سود ممکن است کاهش یابد.
- **مانیتورینگ:** از پیام‌های تلگرام برای نظارت بر عملکرد ربات استفاده کنید.
- **تایم‌فریم:** ربات برای تایم‌فریم 1 دقیقه بهینه شده و در ساعات پرنوسان (جلسه لندن/نیویورک) بهترین عملکرد را دارد.
