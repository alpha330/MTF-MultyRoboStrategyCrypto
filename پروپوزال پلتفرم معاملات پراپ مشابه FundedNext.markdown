# پروپوزال پروژه: پلتفرم معاملات پراپ مشابه FundedNext

## مرور پروژه
هدف این پروژه، توسعه یک پلتفرم معاملات پراپ (Proprietary Trading) مشابه FundedNext است که به تریدرها امکان می‌دهد در چالش‌های ارزیابی شرکت کنند و با سرمایه شبیه‌سازی‌شده (تا 200,000 دلار) در محیطی بدون ریسک معامله کنند. این پلتفرم از معاملات فارکس، فلزات، شاخص‌ها و کالاها پشتیبانی خواهد کرد و برای اتصال به بروکرهای فارکس و صرافی‌های کریپتو در آینده طراحی می‌شود. تکنولوژی‌های مورد استفاده شامل Django REST Framework (بک‌اند)، Next.js (فرانت‌اند)، PostgreSQL (دیتابیس)، Redis (کش و مدیریت سشن)، Celery (صف وظایف) و Docker (کانتینریزاسیون) است. پلتفرم دارای درگاه‌های پرداخت ریالی و کریپتویی خواهد بود و در سه فاز توسعه (توسعه، استیج، پروداکشن) اجرا می‌شود.

## اهداف
- ساخت پلتفرمی مقیاس‌پذیر، امن و کاربرپسند برای مشارکت تریدرها در چالش‌های معاملاتی.
- پیاده‌سازی چالش‌های ارزیابی (مانند Stellar و Express) با قوانینی مثل حداکثر ضرر روزانه 5٪ و ضرر کلی 10٪.
- فراهم کردن دسترسی به حساب‌های فاندشده برای تریدرهایی که چالش‌ها را با موفقیت پشت سر می‌گذارند، با تقسیم سود تا 95٪.
- یکپارچه‌سازی درگاه‌های پرداخت ریالی (مثل زرین‌پال) و کریپتویی (مثل Coinbase Commerce).
- اطمینان از کانتینریزاسیون زیرساخت با Docker برای قابلیت حمل و مقیاس‌پذیری.
- طراحی با قابلیت توسعه برای اتصال به بروکرهای فارکس (مانند Eightcap) و صرافی‌های کریپتو (مانند Binance).
- تحویل محصول حداقل قابل عرضه (MVP) در بازه زمانی مشخص، با بهبودهای تدریجی.

## تکنولوژی‌های مورد استفاده
- **بک‌اند**: Django REST Framework (پایتون) برای توسعه API، احراز هویت و منطق تجاری.
- **فرانت‌اند**: Next.js (ری‌اکت) برای رابط کاربری پاسخگو و بهینه‌شده برای SEO با رندر سمت سرور.
- **دیتابیس**: PostgreSQL برای ذخیره داده‌های رابطه‌ای (پروفایل کاربران، سوابق معاملات، پیشرفت چالش‌ها).
- **کش و مدیریت سشن**: Redis برای کش پاسخ‌های API و مدیریت سشن‌های کاربران.
- **صف وظایف**: Celery برای وظایف ناهمزمان (مثل پردازش پرداخت، اعلان‌های ایمیلی، ارزیابی چالش‌ها).
- **کانتینریزاسیون**: Docker و Docker Compose برای محیط‌های توسعه، استیج و پروداکشن.
- **درگاه‌های پرداخت**:
  - ریالی: زرین‌پال (یا مشابه برای پرداخت با ریال ایران).
  - کریپتویی: Coinbase Commerce یا NOWPayments برای پرداخت‌های کریپتویی (BTC، ETH، USDT).
- **CI/CD**: GitHub Actions یا GitLab CI برای تست و استقرار خودکار.
- **اتصالات آینده**: APIهای بروکرهای فارکس (مانند MetaTrader 4/5) و صرافی‌های کریپتو (مانند Binance، Kraken).

## فازهای توسعه
پروژه در سه فاز اجرا خواهد شد: توسعه، استیج و پروداکشن.

### فاز 1: توسعه (محیط Dev)
- **مدت زمان**: 3-4 ماه
- **اهداف**:
  - راه‌اندازی زیرساخت اصلی (محیط کانتینریزاسیون‌شده، PostgreSQL، Redis، Celery).
  - توسعه APIهای بک‌اند برای مدیریت کاربران، ثبت‌نام در چالش‌ها و شبیه‌سازی معاملات.
  - پیاده‌سازی صفحات فرانت‌اند برای داشبورد کاربر، انتخاب چالش و رابط معاملاتی.
  - یکپارچه‌سازی درگاه‌های پرداخت اولیه (ریالی و کریپتویی).
  - اجرای تست‌های واحد و یکپارچه‌سازی.
- **خروجی‌ها**:
  - APIهای احراز هویت کاربر (ثبت‌نام، ورود، احراز هویت مبتنی بر JWT).
  - APIهای مدیریت چالش (مانند چالش Stellar با اهداف سود و محدودیت‌های ضرر).
  - کامپوننت‌های فرانت‌اند برای ورود کاربران، انتخاب چالش و داشبورد.
  - یکپارچه‌سازی پرداخت برای ثبت‌نام در چالش‌ها (زرین‌پال، Coinbase Commerce).
  - راه‌اندازی کانتینریزاسیون‌شده با PostgreSQL، Redis و Celery.
- **نقاط عطف**:
  - هفته 1-2: راه‌اندازی پروژه (Docker، Django، Next.js).
  - هفته 3-6: احراز هویت کاربر و APIهای چالش.
  - هفته 7-10: توسعه فرانت‌اند و یکپارچه‌سازی پرداخت.
  - هفته 11-14: تست و رفع اشکال.

### فاز 2: استیج (محیط Stage)
- **مدت زمان**: 2-3 ماه
- **اهداف**:
  - استقرار برنامه در محیط استیج برای تست واقعی.
  - اجرای تست پذیرش کاربر (UAT) با گروه کوچکی از تسترهای بتا.
  - بهینه‌سازی عملکرد (مانند کش Redis، ایندکس‌گذاری دیتابیس).
  - تقویت امنیت (مانند محدود کردن نرخ درخواست، محافظت در برابر CSRF/XSS).
  - آماده‌سازی برای مقیاس‌پذیری در سطح پروداکشن.
- **خروجی‌ها**:
  - محیط استیج با خط لوله CI/CD.
  - APIها و فرانت‌اند بهینه‌شده برای عملکرد.
  - بهبودهای امنیتی (مانند OAuth2، پردازش امن پرداخت).
